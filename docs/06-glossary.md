# Glossary — Fraud & Chargebacks

| Term | Definition |
|------|------------|
| **CNP** | Card-Not-Present transaction |
| **Provisional Credit (PC)** | Temporary credit to cardholder during investigation |
| **Chargeback** | Issuer-initiated reversal via card scheme |
| **Representment** | Merchant/acquirer challenge to chargeback with evidence |
| **Reason Code** | Scheme-defined dispute category (e.g. Visa 10.4) |
| **3DS** | 3-D Secure authentication — may shift fraud liability |
| **Compelling Evidence** | Scheme-specific documentation to defend representment |
| **VAMP** | Visa Acquirer Monitoring Program — excessive dispute thresholds |
| **bps** | Basis points — fraud loss as % of volume × 10,000 |
